# Harborline — the fictional brand used in all demos

DTC technical outerwear. Founded 2019. Sells direct, no wholesale.

**Product line**
- Rain shells (`Foulweather Shell`, $285) — 3-layer, taped seams, 20k/20k
- Deck boots (`Slipway Boot`, $165) — vulcanized rubber, wool-lined
- Dry bags (`Tidepack 25L`, $78)

**Real constraints that make critiques bite**
- Average order value $190; CAC $58 and climbing
- 61% of traffic is mobile
- Return rate 14%, mostly sizing on the shell
- Best-selling SKU is the boot, but the shell has the margin
- Competes against Grundéns (commercial fishing heritage) and Stutterheim (fashion-forward)
- Customer base splits: 55% actual boaters, 45% "coastal aesthetic" buyers

**Voice**: understated, technical, no exclamation points. Closer to a spec sheet than a
catalog. The brand never says "adventure."

These details exist so critics can cite something concrete. A critique like "the headline
ignores that 61% of traffic is mobile" is valid. "The headline could be punchier" is not.
